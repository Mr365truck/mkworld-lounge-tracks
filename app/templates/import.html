Paste importer

Accepts the Google Doc format as-is: a header line (date, time, format, min/max/avg mmr, seat) followed by a numbered track list with optional nested sub-items.

What it does with the messy parts

  • Track spellings resolve through the alias table — 45 historical spellings, all mapped.
  • Race numbering restarting mid-block splits into two sessions: the abandoned one and the fresh one.
  • A numbered race with no track is kept, with no track. Dropping it would hide a real gap.
  • Missing dates inherit from the block above; missing times default to midnight.
  • Tournament rooms get expected_races = 8; everything else 12.
  • variant defaults to 3lap; shortcut_hit to NULL — never na, since the doc records neither.
  • Anything unresolved goes to the review queue in Settings, never silently dropped.
